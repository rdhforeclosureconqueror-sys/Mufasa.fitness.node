# Leaderboard Checks

A true `GAMIFICATION_LEADERBOARDS` flag is not proof of a gamification leaderboard. The existing consent-based push-up challenge leaderboard is a separate feature. The launch health check requires a ranking service/projection, privacy and visibility policy, deterministic ties, member read route, member UI, isolation, and safe empty state. These are absent, so the enabled flag is classified `FLAG_ENABLED_BUT_FEATURE_NOT_IMPLEMENTED`.
