# Capability registry

The versioned registry declares build compatibility, production AI Coach, optional diagnostic summarizer, designated member journey, in-app notifications, universal XP leaderboards, separate Push-Up Challenge leaderboard, and optional Avatar. A feature flag alone is never implementation evidence.

Notification readiness requires event source, append-only persistence, replay projection, member routes, UI, deduplication, unread integrity, and honest in-app-only delivery. Universal leaderboard readiness requires authoritative ledger projection, deterministic ranking, privacy policy/preferences, member routes/UI, and calculation freshness. Restored Greatness and Push-Up event contracts are diagnostic evidence but do not imply XP eligibility.
