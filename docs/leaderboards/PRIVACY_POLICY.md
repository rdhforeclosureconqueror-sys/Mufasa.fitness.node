# Universal leaderboard privacy policy

Participation uses an explicit member visibility preference and supports immediate opt-out/private mode. The default public label is a masked alias (`Member ••••`). A member may select profile-name display, but email-shaped names are replaced by the alias and output is capped at 40 characters.

Excluded: opted-out members, banned members when that state is supported, administrative/operator accounts, and members below minimum XP. Never ranked or returned: email, phone, precise location, bodyweight, calories, nutrition, assessment data, health conditions, raw user IDs, or event payloads. The requester can see their own public position but cannot access another member's private position.
