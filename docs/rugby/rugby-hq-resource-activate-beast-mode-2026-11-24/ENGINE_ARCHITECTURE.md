# Adult Activate Engine Architecture

## Engine model

The engine has two delivery modes and four session parts.

### Delivery modes

Structured Mode:
- dedicated Activate block
- best for new athletes, new levels, large groups and teaching
- movement learning mode

Integrated Mode:
- Activate qualities embedded into rugby drills, games, contests, tackle prep, breakdown prep and conditioning
- best after players know the standards
- movement application mode

## Adult session parts

### Part A — Running-based preparation and change of direction

Purpose:
- raise pulse
- warm body
- rehearse running mechanics
- develop coordination
- prepare change-of-direction ability
- maintain trunk/lower-limb control

### Part B — Mobility, resistance and static balance

Purpose:
- develop stability and mobility
- build static balance
- introduce controlled resistance
- organize upper and lower body

### Part C — Resistance, dynamic balance, change of direction and plyometrics

Purpose:
- develop strength
- improve mobility
- train dynamic balance
- train lower-limb/trunk control
- introduce power expression

### Part D — Neck resistance and sprint conditioning

Purpose:
- improve neck function
- develop anaerobic/repeated sprint conditioning
- prepare for high-output rugby demands

## Coaching loop

Teach → Observe → Correct → Reinforce → Progress

When quality breaks:

Regress → Reduce volume → Rebuild control

## Progression principle

Time suggests progression. Movement quality decides progression.
