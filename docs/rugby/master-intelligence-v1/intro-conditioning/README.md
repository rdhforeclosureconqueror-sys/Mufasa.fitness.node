# Rugby HQ Resource Pack for Mufasa Fit

This pack harvests the rugby-conditioning thread into repo-ready resources for the Mufasa Fit Rugby HQ website and bot.

It is based on the completed World Rugby awareness course: **Introduction to Conditioning - Adults - Pre-Level 1 (Online)**, plus the custom Rugby HQ ideas developed in the thread.

## Install into a Node repo

Copy the folder into or beside your repo, then from repo root run:

```bash
bash rugby_hq_resource_pack/scripts/install_into_repo.sh
```

This installs:

- `docs/rugby-hq/`
- `src/rugby-hq/data/`
- `src/rugby-hq/prompts/`
- `src/rugby-hq/schemas/`
- `src/rugby-hq/index.js`

## Safety positioning

Use Rugby HQ as a **coaching and performance system**, not a medical diagnostic system. Pain, suspected injury, concussion, or serious dysfunction should trigger referral to a qualified medical professional.
