# Gym, Strength, Power, Olympic Derivatives and Strongman

## Movement families
Use:
squat, hinge, lunge, push, pull, carry, jump/land.

A weekly plan should cover needs across the microcycle; every pattern does not need to appear every session.

## Exercise selection
Need → movement family → adaptation → competency → equipment/logistics → exact exercise.

Tag exercises by:
- movement/joints
- force direction
- contraction type
- velocity
- complexity
- equipment
- prerequisites
- progression/regression
- safety tags

Specificity is biomechanical and physiological, not visual resemblance alone.

## Session design
Explicitly prescribe:
- timing
- format
- selection
- order
- exercise number
- sets/reps/load
- rest
- cueing
- setup/transition time

Default order:
power/skill → primary strength → accessory → isolation
Priority and special methods can override this.

Do not generate more work than fits the actual session duration. Instruction, setup, transitions and equipment changes count.

## Rest
Course guides:
- strength endurance: ~30–60 s
- hypertrophy: ~90 s–3 min
- strength: ~3–5 min
- power: ~2–4 min
Rest changes the stimulus. Multi-joint work may need more than isolation. Use output/VBT to extend rest when appropriate. If logistics are the problem, alter format/stations/exercise count before destroying critical rest.

## Cueing
External focus is often useful for performance/explosive tasks.
Internal focus can be useful for specific technical/muscular goals.
Use one primary cue at a time where possible.
Store athlete-specific cues that worked.

## Olympic lifts
Useful but optional.
Weigh expected power benefit against learning time, technical cost, equipment and supervision.
Valid alternatives include loaded jumps, plyometrics, throws and sprints.

Derivatives are valid endpoints:
jump shrug → clean pull → high pull → hang power clean → power clean → full clean only if useful.

Competency gates:
- pain-free positions
- rack tolerance if a catch is used
- squat/trunk/balance control
- coaching/supervision
- suitable equipment

General resistance progression:
posture/position → movement → resistance

Olympic-lift progression:
posture/position → movement → speed → resistance

Do not load poor technique.
Do not encode the course cue of deliberately shifting bodyweight onto the forefoot from the floor; use a balanced midfoot-oriented start.
An overhead squat is not a mandatory clean gateway.

## Strongman
Sleds, ropes, kettlebells, tyres, sandbags, carries and drags are optional methods.
Adaptation depends on load, speed, distance, duration, rest and intent.
Awkwardness/instability is not automatically superior.
Tyre flips are not direct tackle/scrum replicas.
Heavy sled work complements rather than replaces free sprinting.
Carries can target grip, trunk, strength, endurance or conditioning depending on dose.
