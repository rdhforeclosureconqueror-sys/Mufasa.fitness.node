# Game Demands and Conditioning

## Rugby demand model
MATCH DEMANDS = LOCOMOTION + COLLISION/CONTACT + POSITION + LEVEL + AGE + SEX + FORMAT + TEAM STYLE + PEAK PASSAGES

Whole-match averages are useful but insufficient.

## Locomotion
Store:
- total distance
- m/min
- high-speed running
- sprint distance/count
- acceleration
- deceleration
- maximal speed
- high-metabolic-load or similar composite metrics if used

Absolute and individualized HSR thresholds are different and must preserve method.

## Collision/contact
Forwards generally face more frequent contacts; backs may have fewer but sometimes higher-speed events. Context matters.
Store:
- count
- intensity/magnitude where validated
- role: tackler / ball carrier
- approach speed if available
- event confidence / algorithm

Momentum is mass × velocity, but do not reduce collision demand to momentum alone.
Raw >10g accelerometer events are not automatically verified collisions.

## Peak passages
Prefer rolling windows when raw data permit.
Useful windows: 15 s, 30 s, 1, 2, 3, 5 and 10 min.
Peak intensity falls as the window length grows.
Store locomotor peak, contact peak and combined peak separately where possible.
Peak match values are reference ceilings, not an automatic training prescription.

## Conditioning capacities
Separate:
- aerobic power
- aerobic capacity
- anaerobic power
- anaerobic capacity
- RSA
- RHIE
- peak output
- repeatability / decrement
- recovery characteristics

RSA is narrower than RHIE. RHIE can include sprints, accelerations, tackles, carries, rucks and mauls.

## Physiology
The ATP-PCr, glycolytic and oxidative systems contribute together.
Aerobic metabolism supports repeated-effort recovery and phosphocreatine restoration.
Do not explain fatigue as simply “lactic acid.”

## Training RSA/RHIE
Train the limiting factor:
- aerobic recovery
- peak speed/power
- alactic power
- alactic capacity
- glycolytic/RHIE-specific tolerance
- rugby-specific contact repeatability

A poor RSA test does not automatically mean “do more of the RSA test.”

## MAS
Field MAS is a practical individualized aerobic-running estimate and is distinct from laboratory-measured vVO2max.
Typical course field test: roughly 5–7 min, often 1200–1600 m.
Formulas:
- m/s = distance / time
- m/min = m/s × 60
- km/h = m/s × 3.6
Preserve test distance, time, surface and protocol.
Example preserved from thread: 1200 m in 5:03 (303 s) ≈ 3.96 m/s, 237.6 m/min, 14.3 km/h.

## Tempo
Define the word.
Threshold-oriented tempo is primarily aerobic, not “pure glycolytic.”
Sprint-style tempo around 65–75% of sprint-speed reference can support lower-intensity aerobic/recovery work and movement quality.
A 60 m average speed is not true MSS.
