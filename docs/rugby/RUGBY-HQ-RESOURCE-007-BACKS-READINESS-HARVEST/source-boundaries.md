# Source Boundaries and Safety Notes

## Source-derived from uploaded Pocket PT prototype

The uploaded Pocket PT Rugby Coaching OS README states the prototype includes a Coach Command Center, roster, player development record, transparent starter/bench/developing status, coach-verified competency acknowledgments, scrum prerequisite graph, training planner, evidence-informed Starting XV board, player welfare/concussion recognition workflow, restricted safeguarding workspace, coach-readiness checklist, and DFW Academy pathway.

The prototype README also states important boundaries: the prototype is independent, not endorsed by USA Rugby or World Rugby, and internal Pocket PT acknowledgments do not replace official accreditation, Rugby Xplorer registration, medical clearance, competition-specific front-row eligibility, SafeSport/background screening, statutory safeguarding duties, or professional safeguarding investigation.

## Thread-derived Pocket PT / Rugby HQ methodology

The thread established that backs need a system equivalent to forwards Rugby Ready:

- Forwards already have a clearer path through scrum/contact readiness.
- Backs need space-defense, decision, movement, tackling-in-space, and role-IQ readiness.
- Backs should see a player-facing rating card that explains starter eligibility.
- Skill/IQ readiness must be separated from fitness/combine testing.
- Speed alone must not make a player starter eligible.
- Unsafe tackling, poor defensive reads, or inability to understand spacing should cap or block starter eligibility.

## Proposed software logic

The following are proposed internal Rugby HQ logic, not official rugby certifications:

- 1–99 Backline Skill/IQ Rating.
- 1–99 Backline Athletic Index.
- Readiness bands.
- Category weights.
- Hard gate for tackling-in-space below 70.
- Coach evidence types.
- Position overlays for 10, 12, 13, wing, and 15.
- Machine schemas and activation maps.
