# RUGBY-HQ-RESOURCE-007: Backs Readiness Thread Harvest

This directory preserves the Rugby HQ knowledge recovered from the Pocket PT / Rugby HQ coaching-system thread about creating the backs equivalent of forwards Rugby Ready.

## Scope

- Backs Rugby Ready for positions 10, 12, 13, wings 11/14, and 15.
- 1–99 Backline Skill/IQ Rating.
- Separate 1–99 Backline Athletic Index.
- Defensive IQ and tackling-in-space assessment.
- Offensive with-ball and off-ball assessment.
- Position-specific overlays.
- Coach observation evidence records.
- Starter eligibility hard gates.
- Fitness/combine-style tests for backs.
- Integration guidance for Rugby HQ, Rugby Passport, Combine Assessment Engine, Athlete Attribute Engine, Rugby Ready competency tracking, Coach Headquarters, tactical simulator, and digital athlete development.

## Non-scope

This resource does not implement the whole system. It does not create a second athlete identity model, official certification system, or medical/safeguarding decision system.

## Machine-readable companions

```text
data/rugby/backs-readiness-resource-007/
```

## Critical design rule

Do not mix these three record classes in one permission space:

1. Performance and coaching notes.
2. Medical/welfare restrictions.
3. Safeguarding reports or narratives.
