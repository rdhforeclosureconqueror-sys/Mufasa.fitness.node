# Rugby HQ Integration Map

This resource extends existing Rugby HQ architecture and should not replace it.

## Rugby Passport

Attach evaluations to the existing athlete development record. Do not create a second athlete profile.

## Position Intelligence for all 15 positions

This resource covers 10, 12, 13, wings 11/14, and 15. It should plug into a full 15-position intelligence layer.

## Professional performance benchmarks

This resource defines internal readiness bands but does not define verified professional benchmarks.

## Combine Assessment Engine

Use the Backline Athletic Index as a rugby-specific combine test battery.

## Athlete Attribute Engine

Map Skill/IQ categories and Athletic Index categories into attributes. Do not allow Athletic Index to override hard safety gates.

## Individual development programs

Each low score should produce a next action with goal, drill, coaching cue, success measure, and reassessment date.

## Exercise Intelligence Library

Map tests/drills such as get-up sprint repeat drill, T-test, 5-10-5 shuttle, reactive cone drill, Bronco, beep test, broad jump, vertical jump, medicine ball throw, 2v1, 3v2, tackle tracking drill, 13/wing drift drill, kick chase, and high-ball work.

## Activate and Beast Mode

Activate remains preparation/injury-reduction warm-up context. Beast Mode can use Athletic Index gaps to select conditioning or power work. Keep skill/IQ evaluation separate from conditioning workouts.

## Rugby Ready competency tracking

This resource creates a backs Rugby Ready equivalent using evidence and coach verification. It does not replace official Rugby Ready, World Rugby, or USA Rugby accreditation.

## Training periodization

Use scores to focus training blocks.

## Coach Headquarters

Show backs readiness summary, hard-gate blockers, position battles, lowest scoring competencies, next reassessment actions, and evidence confidence.

## Tactical simulator and digital athlete development

Use this resource to simulate defensive line spacing, drift vs press decisions, edge defense, backfield coverage, attacking depth/width/timing, support lines, and role-specific decisions.

## Professional scouting and athlete pathways

The 1–99 scores are internal program ratings. Scouting exports should show evidence-backed competencies, trends, and verified combine results, not unverified pro-level claims.
