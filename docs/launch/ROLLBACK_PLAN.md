# Launch Rollback Plan

For UI/navigation/Yoga regressions, revert the focused launch-integration commit and redeploy the previous immutable artifact. Disable gamification/Yoga/AI flags before rollback when they isolate the fault. Do not delete append-only events, awards, ledgers, corrections, or published content generations.

If a completion event was incorrectly accepted, use supported additive correction/reversal and replay; never directly decrement XP. If a content release is faulty, use the permissioned additive rollback endpoint. If storage integrity is uncertain, stop mutations, snapshot evidence, verify audit/checksum chains, restore only from a verified backup, and reconcile append-only events written after that backup. Data rollback limitations and replay/correction outcomes must be communicated before traffic resumes.
