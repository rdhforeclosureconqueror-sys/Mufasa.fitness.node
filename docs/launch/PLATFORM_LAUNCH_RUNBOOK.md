# Platform launch runbook

Deploy but do not automatically enable external checks. Configure persistent storage, complete gamification flags, AI provider/model settings, and optional summarizer settings. Validate routes, deterministic diagnostics, owner isolation, privacy, accessibility, and responsive dashboard. Use an approved acceptance fixture for writes. GO for deterministic and in-app testing when build, storage, notifications, and leaderboards are READY; full provider testing is GO WITH LIMITATIONS until explicit AI/Stripe external checks succeed. Roll back application revision and flags without deleting ledgers, notifications, or audit logs.
