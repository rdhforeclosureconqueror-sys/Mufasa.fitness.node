# End-to-End Acceptance

Automated domain tests exercise onboarding recommendations, Program Engine generation/adaptation, authoritative workout persistence/event emission, replay-safe gamification, Exercise Hub isolation/curation, Yoga persistence and idempotency, and AI Coach context/safety. Launch structural tests verify discoverable navigation and truthful camera-optional Yoga messaging.

Deterministic fixture states should be created in temporary repository stores, never committed credentials: new/no-program; onboarded/no-completion; active/workout+Yoga+XP; 99-XP near-level; clean reward-unlock; deload; optional-projection-empty; and permission-specific author/reviewer/publisher accounts. Authentication tokens are generated in tests with ephemeral secrets.

The full clean-account browser sequence—register, onboard, program, workout, reward/celebration, Yoga, Exercise Hub, AI follow-up, return continuity—was not executed across all required browsers. It remains a launch blocker rather than being inferred from unit/integration tests.
