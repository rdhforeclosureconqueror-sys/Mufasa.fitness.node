# Future Ideas Parking Lot

This file records possibilities without scheduling them. Only items marked **Immediate** belong to the planning foundation; they are not permission to implement features. Moving an idea into a phase requires an owner, evidence, privacy/safety review, acceptance criteria and an updated master dependency map.

|---|---|---|

## Experimental — prototype only behind research controls

| Knowledge extraction from prose | Provenance-aware parser and reviewer workflow | Parsed text is approved executable policy |

## Do Not Pursue — unless an explicit governance reversal is approved

| Idea | Reason |
|---|---|
| Revive/deploy the legacy Express, SQLite, Firebase or Python runtime | Duplicates and weakens the current production architecture |
| Read `public/new/` directly in production | Unversioned, unreviewed, public staging data |
| Diagnose injury, tight/weak muscles or medical conditions from pose/OHSA landmarks | Evidence and product authority are insufficient; unsafe health claim |
| Auto-prescribe advanced gymnastics or approve mastery from computer vision | High consequence, incomplete progression/safety data |
| Reward pain tolerance, extreme flexibility, dangerous difficulty or raw sensor confidence | Creates harmful incentives |
| Store raw camera/video by default | Unnecessary privacy/retention exposure |
| Use an LLM as the source of measurements, safety gates, eligibility, thresholds or awards | Non-deterministic and unauditable authority |
| Publish a single unexplained “percent correct” score | Misleading precision and hides visibility/recognition/alignment uncertainty |
| Random row splits on current yoga CSVs and report model accuracy | Likely source/subject leakage and no defensible external validity |
| Treat MediaPipe predictions as ground-truth annotations or a way to retrain MoveNet | Model output is not independent truth and conventions differ |

## Parking-lot maintenance

Each addition needs a category, one-sentence value, prerequisites, prohibited assumptions and owner. Review quarterly only after active phase work exists. Do not estimate, schedule or create production dependencies from this file.
