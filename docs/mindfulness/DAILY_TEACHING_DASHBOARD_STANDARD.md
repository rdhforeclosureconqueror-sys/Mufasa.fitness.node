# Daily Teaching Dashboard Standard

## Purpose

Every Mindfulness Dashboard path uses one familiar daily-learning rhythm. The active path changes the **center of the lesson**; it does not change how a member learns, reflects, affirms, or practices.

## Shared daily snapshot

1. Date
2. Today's reflection name
3. Center teaching visual/card
4. What the teaching means in everyday life
5. Today's affirmation
6. Today's awareness challenge or practice
7. Optional deeper learning, reflection, and sharing actions

The daily card is the visual anchor. The text below it makes that anchor useful in a member's real day.

## Track centers

| Path | Center of the day | Snapshot title | Supporting content |
|---|---|---|---|
| Chakra Mindfulness | Day's chakra | Chakra name | Meaning, affirmation, awareness challenge, grounding practice |
| Eight Limbs of Yoga | Day's lesson within the current limb | Lesson name and limb | Plain-language lesson, relevant chakra/affirmation, awareness challenge, practice |
| Adinkra Wisdom | Day's Adinkra lesson | Adinkra symbol and lesson | Meaning, story/bridge, affirmation, awareness challenge, community application |

## Implementation rules

- Keep the date and reflection position consistent across all three paths.
- Do not show a generic chakra snapshot when a member is in Eight Limbs or Adinkra Wisdom mode.
- In Eight Limbs, the day's lesson is primary; any chakra is supportive context, not the center.
- In Adinkra Wisdom, the day's Adinkra lesson is primary; the symbol, meaning, and lived application lead the page.
- Preserve the same accessible image treatment, mobile layout, and share/copy actions for every track.
