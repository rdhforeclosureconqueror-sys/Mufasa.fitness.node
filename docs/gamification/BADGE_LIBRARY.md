# Initial Badge Library

## Catalogue rules

This is a proposed launch catalogue, not approved production policy. Every criterion is evaluated from verified server events, is versioned, and is subject to the caps in `POINTS_AND_XP.md`. Rarity describes expected healthy time/consistency, not randomized odds. Tier families keep stable family IDs and distinct tier badge IDs. Icon concepts require original, accessible artwork and localized alt text; color is never the only tier cue.

## Catalogue acceptance criteria

Before publication, every badge has stable IDs, typed criteria, event schema allow-list, safe evidence summary, repeatability, caps, effective interval, translations, icon/alt text, rarity rationale, XP overlap group, and approvals. Automated validation proves all references resolve, tier thresholds increase, future badges are inactive, maximum issuance is bounded, and no prohibited safety criterion appears.
