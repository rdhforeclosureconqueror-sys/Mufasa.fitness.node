# Codex handoff — Experiment Manager E0–E8

Implement and maintain the Experiment Manager as a bounded extension of the shared Business OS. Reuse the role registry, organizational coordinator, constitutional grants, canonical proposal/result artifacts, Economics, Learning, readiness, and Academy systems.

Required regression coverage includes lifecycle transitions, version immutability, human approval and budget ceilings, missing versus measured zero, result classes, duplicate run protection, coordinator authority, and false success rejection. Any future live adapter, Test A execution, external contact, publication, expenditure, or scaling work requires a separate approved plan and human authority; it is outside this handoff.

Readiness reporting must distinguish architecture-ready, internal-integration, live-enabled, and human-accepted gates. Never promote Academy output to live or human evidence.
