# SMART_ANALYST Platinum

SMART_ANALYST is a governed role configuration on the existing shared Brain, not a second agent runtime. This implementation separates **architecture readiness** from **live Platinum certification** and preserves controlled Test A as non-independent evidence.

## Construction set

- [Implementation contract](IMPLEMENTATION_CONTRACT.md)
- [42-scenario Academy matrix](ACADEMY_MATRIX.md)
- [Codex handoff and phase evidence](CODEX_HANDOFF.md)

The Analyst may read governed evidence, compare it, create attributable assessments and evidence requests, and recommend a bounded experiment. It may not contact prospects, publish, spend, change prices, execute Test A, mutate external accounts, or certify itself.
