TITLE: LEGO TRAINING BLOCKS – UNIVERSAL SYSTEM

GOAL:
Give the coach a small set of building blocks that can be combined into any workout. A “block” = movement pattern + intensity + time/rep scheme + focus (strength, power, mobility, stability, endurance).

MOVEMENT PATTERNS (LOWER BODY)
- SQUAT: knee-dominant (air squat, goblet squat, front squat, split squat, step-up)
- HINGE: hip-dominant (good morning, Romanian deadlift, hip bridge, hip thrust)
- LUNGE: single-leg control (forward, reverse, lateral, walking, curtsy)
- JUMP / LAND: power + landing mechanics (vertical, broad, box jump, rebound jump)
- CHANGE OF DIRECTION: shuffle, carioca, cut, backpedal, pivot

MOVEMENT PATTERNS (UPPER BODY)
- HORIZONTAL PUSH: push-up variations, bench press
- VERTICAL PUSH: overhead press, handstand press progressions
- HORIZONTAL PULL: row variations
- VERTICAL PULL: pull-up / chin-up progressions
- SUPPORT / HOLD: plank variations, hollow hold, arch hold, support on bars

CORE PATTERNS
- ANTI-EXTENSION: plank, dead bug, body saw
- ANTI-ROTATION: pallof press, suitcase carry
- ROTATION: Russian twist, medicine-ball throw, twist jumps
- LATERAL STABILITY: side plank, lateral hops, Cossack squat

PLANES OF MOTION
- SAGITTAL: forward / backward (squat, lunge, tuck jump)
- FRONTAL: side-to-side (lateral lunge, side shuffle, straddle jump)
- TRANSVERSE: rotation (twist jumps, pirouettes, turn sequences)

INTENSITY “GEARS”
- GEAR 1 – MOBILITY / PATTERNING
  Slow tempo, bodyweight or light load, long time under tension, focus on perfect alignment.
- GEAR 2 – STABILITY / STRENGTH
  Moderate tempo, controlled eccentrics, 6–12 reps, 2–4 sets, rest 45–90 sec.
- GEAR 3 – POWER / SPEED
  Explosive intent, low reps (2–6), 3–5 sets, full rest 60–180 sec.
- GEAR 4 – CONDITIONING / DENSITY
  Circuits, EMOMs, AMRAPs, 8–20 minutes, lighter load but sustained effort.

LEGO BLOCK TYPES
- WARM-UP BLOCK (5–10 min)
  1) Tissue prep (foam roll / light drills)
  2) Dynamic mobility (leg swings, arm circles, hip circles)
  3) Activation (glute bridge, band pull-apart, plank)

- SKILL BLOCK (10–20 min)
  Choose 1–2 high-focus skills (e.g. handstand line, kip drill, beam series). Use low fatigue, high quality.

- STRENGTH BLOCK (10–20 min)
  Pick 2–4 patterns (squat, hinge, push, pull). 3–4 sets each in Gear 2 or Gear 3.

- ACCESSORY / PREHAB BLOCK (5–15 min)
  Small muscles, joint stability, balance, core, rotator cuff, ankle work.

- CONDITIONING / DANCE BLOCK (5–15 min)
  Tumbling passes, dance sections, choreography run-throughs, or short circuits.

COMBINING BLOCKS
- Short session (30 min): WARM-UP + SKILL + STRENGTH
- Standard session (60 min): WARM-UP + SKILL + STRENGTH + ACCESSORY
- High-volume (90 min): WARM-UP + SKILL (2 parts) + STRENGTH + CONDITIONING

KEY PRINCIPLES
- Always preserve technique on skill and power work.
- Fatigue work (conditioning) comes AFTER high-skill work.
- Monotony kills motivation: rotate patterns, planes, and intensity gears.
