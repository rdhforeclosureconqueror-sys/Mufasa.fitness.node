# Aligned Yoga Import Quarantine Manifest

## Provenance and policy

The quarantined tree was moved verbatim from `public/new/` to `imported/` on 2026-08-26. Its README identifies the upstream project as `katjawittfoth/Aligned_Yoga_App`. A top-level MIT file exists, but there is no file-level provenance for the media, datasets, generated keypoints, presentation, or copied third-party web assets. Accordingly, **every imported item remains `reference_only`**; the presence of that license was not treated as proof that every artifact is covered.

Nothing under this directory is served or imported by production. Three pre-existing Greatness campaign images remain at `public/new/` because the current static experience requires them; they are recorded as `NEEDS_REVIEW`, not approved as Aligned assets. Pocket PT code in `src/yoga/camera-coach/` is a clean-room, provider-neutral implementation informed by concepts rather than copied code.
