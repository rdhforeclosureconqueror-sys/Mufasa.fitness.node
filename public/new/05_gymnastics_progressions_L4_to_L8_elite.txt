TITLE: PROGRESSION ROADMAP – LEVEL 4 TO LEVEL 8/ELITE STYLE

PURPOSE:
Give the coach a mental map of how base skills in Level 4–5 grow into advanced skills. This helps design progressions and Lego-style drills.

FLOOR PROGRESSION EXAMPLES
- Cartwheel → Round-off → Round-off back handspring → Round-off back handspring series → Round-off BHS layout / full.
- Back walkover → Back handspring step-out → Two-foot back handspring → Layout.
- Front walkover → Front handspring step-out → Front handspring → Front tuck / layout.

CORE DRILLS ACROSS LEVELS
- HANDSTAND FOUNDATION:
  - Level 4–5: wall handstand holds, shoulder taps, line drills.
  - Level 6–8: handstand walking, pirouette drills, press handstand work.

- BLOCKING AND REBOUND:
  - Board jumps, handstand flatback.
  - Handspring vaults → tsuk / yurchenko style drills (long-term).

- TWIST PREP:
  - Trampoline / tumble track half and full turns from jumps.
  - Layout shapes with quarter/half turns, spotting awareness.

BEAM PROGRESSIONS
- From handstand step-downs and cartwheels on low beam to flight series.
- Emphasis on: lock-knee landing, hip square vs. open, focus point control.
- Use floor beam → low beam → competition height progression.

BARS PROGRESSIONS
- KIP PATHWAY:
  Glide swing → glide + piked snap → stop to support → kip.
- CASTING PATHWAY:
  Small casts to horizontal → higher casts focusing on hollow + shrug.
- CIRCLE SKILLS:
  Back hip circle → clear hip progressions → giant swing basics on strap bar.

PHYSICAL PREP FOR LEVEL 6–8 JUMP
- Relative strength: pull-ups, strict push-ups, deep squats, single-leg balance.
- Power: box jumps, bound series, medicine-ball throws.
- Core: compression work (pike / stalder shape), side bends, anti-rotation.
- Flexibility: oversplits carefully dosed, bridge progressions for shoulders.

MENTAL COACHING
- Build a growth mindset: “We level up shapes and control first, skills second.”
- Use small, frequent wins (checklists, badges, skill trees).
- Normalize spotting and safety equipment; courage is trained, not demanded.

USAGE:
Treat this file as a high-level map. Combine it with Lego Training Blocks to generate:
- Drills that connect current level skills to future goals.
- Event-specific strength blocks tied directly to progressions.
