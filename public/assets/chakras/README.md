# Milele Fit — Daily Chakra Artwork

Place chakra PNG assets in this folder. The Mindfulness Dashboard will use two separate assets per day: a small **symbol** on the daily snapshot and a full **card** for the day's teaching.

## Intended dashboard behavior

1. Snapshot of the Day shows the day's reflection, awareness challenge and **symbol only** (not the educational card).
2. Clicking or tapping the snapshot opens or scrolls to that day's full chakra card.
3. The chakra card follows the snapshot and displays the full teaching image.
4. The same day-to-chakra mapping must be used for both assets; the card should update on the same daily boundary as the snapshot.
5. Provide descriptive image alt text and a graceful fallback while artwork is missing.
